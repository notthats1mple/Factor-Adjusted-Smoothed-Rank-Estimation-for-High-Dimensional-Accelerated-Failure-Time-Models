# Review and contributions

Use GitHub Issues for reproducibility questions or a proposed correction. Identify the manuscript version, section or equation, expected behavior, and a concise reproducer where applicable. For numerical claims, state the cohort, method, tuning value, stopping criterion, and source record.

Keep mathematical changes separate from editorial changes. A mathematical correction should identify the previous statement, revised statement, affected assumptions, and proof dependencies. Preserve reported failures and existing evidence identities.

The repository supports manuscript compilation and review. New fitting, simulation, or data analysis belongs in a separately specified research task.
